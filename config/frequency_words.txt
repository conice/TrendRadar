#维护方法
# 1. 词组必须以 [组名] 开头；组与组之间用空行分隔。
# 2. 标准格式：
#    [组名]
#    /中文正则/
#    /英文正则/
# 3. 中文正则只放中文关键词；英文正则只放英文关键词，不要混行。
# 4. 中文关键词翻译成英文时，使用新闻标题里常见的自然表达，不要逐字直译。
# 5. 同一个关键词只允许出现在一个词组的对应语言行内；新词组先用全文搜索查重。
# 6. 英文品牌、产品、人物或组织如果没有对应中文别名，可只写英文正则，并在组名下加：
#    # 没有中文正则
# 7. 删除或合并词组时，保留命中更多新闻的组名；删除前先确认没有唯一关键词被误删。
# 8. 添加关键词后，用项目解析器和新闻样本验证：解析无误、无空组、无重复、命中稳定。
# 9. 不要添加泛词和兜底规则；优先补充具体品牌、机构、事件、领域和自然表达。
# 10. 修改后保持 [GLOBAL_FILTER] 在最前，[WORD_GROUPS] 在其后，不改变解析器依赖的结构。
