# TrendRadar 关键词配置
# 整理依据：本地「新闻仅标题.csv」；任务与统计见 docs/关键词整理任务.md。
#
# 维护方法：
# 1. 层级为 [分组名称] → ## 分类 → ### 子分类 → 关键词。
#    先定位分类和子分类，再每行添加一个关键词。
# 2. 同组关键词是“或”的关系；只在两个分组之间留空行。
# 3. 组内不要插入空行，否则程序会把后续关键词当成新组。
# 4. 中文直接写词；英文用单关键词边界规则，程序自动忽略大小写。
#    例如 /(?<![a-z])AI(?![a-z])/ 能匹配 AI、AI应用，避开 MAIL。
#    英文可与数字相邻，便于匹配 iOS18、GPT5 等版本写法。
#    同一词的写法变体合并为一行：单复数 s?、(es)?，连字符或空格 [- ]、[- ]?、 ?，
#    英美拼写 ou?r、i[sz]ation、a?e，例如 /(?<![a-z])zero[- ]?day(?![a-z])/。
#    不把多个独立关键词并在一行；融资金额句式是唯一例外，集中为一条正则。
# 5. 标题归入第一个命中组；具体主题在品牌与综合平台之前。
#    导航与地理信息排在航天之前，避免遥感、导航标题被“卫星”抢先归组。
# 6. 同名词优先用完整名称或领域短语，例如 CNN模型、RPA软件。
# 7. 子分类按固定主题顺序；组内中文按拼音、英文按名称与数字自然顺序。
#
# 下方为全局过滤区：命中任一词的标题直接排除，优先于所有分组。
# 只放营销、导购类词；降价、补贴、预订、带货、史低等词常见于正常新闻，不放这里。
